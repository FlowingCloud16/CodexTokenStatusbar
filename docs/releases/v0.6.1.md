# v0.6.1 · 轻量免 Node 版

Windows Codex 内嵌状态栏，显示当前对话的速度、缓存命中率、Token 用量和 API 估算费用。

## 下载与使用

下载下方的 **CodexTokenStatusbar-0.6.1.exe**。正常打开 Codex，再双击 EXE 即可；无需安装 Node.js，无需打开调试端口，无需为加载状态栏而重启客户端。

升级前请在托盘退出旧加载器。关闭主窗口只会收进托盘。

## 本版内容

- 使用 Windows 系统运行库，EXE 为 **206,848 字节（202 KiB）**。
- 内嵌速度、缓存、用量和费用，支持三种布局、中文跟随、深浅主题和轻柔动画。
- C# 后台负责统计、费用和连接，不携带或启动外部 Node。
- 修复通过加载器打开客户端后任务栏图标异常的问题，并为加载器补齐独立图标。

## 兼容范围

Windows 11 x64；实测 `OpenAI.Codex` 安装包版本 `26.1103.7773.0`，V8 `15.7.112.23`。客户端底层接口变化时可能需要适配。

已验证运行中客户端的注入、卸载、重连和系统注册入口激活；客户端完全退出后的完整启动流程尚未单独验收。当前程序未签名。

API 费用为估算，不代表订阅扣款或实际账单。内置价格表核对日期为 2026-11-09。
