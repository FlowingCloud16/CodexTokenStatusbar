# v0.6.2 · 生成速度计算更新

本版参照 [dongyue-19/codex-statusbar](https://github.com/dongyue-19/codex-statusbar) 的速度算法，替换之前包含等待和工具执行的整轮平均速度。

## 变化

- 使用官方输出 Token，除以 `Reasoning`、`AgentMessage` 的合并输出时间。
- 重叠输出窗口只计一次，工具执行不单独加入分母。
- 使用 0.35 指数平滑，工具运行或等待新采样时保留上次结果。
- 完成后保留该轮生成速度，下一轮重新采样；不再用整轮吞吐代替生成速度。
- 保留中文跟随、三种布局、计费和现有界面，没有增加常驻说明文字。
- 按 MIT 许可证保留参考项目署名，许可文件随 EXE 内嵌。
- 首次读取和旧用量载体切换时重新确认输出基线，避免历史累计导致速度虚高；输入压缩不清除有效速度。

## 下载与使用

下载 **CodexTokenStatusbar-0.6.2.exe**，先从托盘退出旧加载器，再打开新版。Codex 可以保持运行。

EXE 为 **213,504 字节（208.5 KiB）**，无需安装 Node.js。继续支持 Windows 11 x64，客户端兼容范围与 0.6.1 相同；当前未签名。

速度仍是基于官方计数和模型输出窗口的估算，包含推理 Token；不是逐 Token 瞬时速度。缺少完整证据时显示等待。

## 验证

95 项单元测试、207 项 JavaScript/C# 对照、4 个本机脱敏日志回放检查点，以及界面、语言、对话切换和免 Node 成品检查通过。真实数据验证采用只读回放；本版尚未在现有客户端窗口中切换加载器实测。
